# dzup-ui Component Library

Welcome to the **dzup-ui** component library — **163 Vue 3 component files** across
**11 families**, built with TypeScript, Tailwind CSS 4, and a three-tier design-token
system.

> **Enterprise components** (Kanban, Gantt, FormBuilder, WorkflowDesigner, etc.) are
> available in [@dzup-ui/pro](https://github.com/datazup/dzup-ui-pro) under a
> commercial license.

## Start here

- **[Getting Started](?path=/docs/getting-started--docs)** — install, wire tokens, first component.
- **[Guides/Theming](?path=/docs/guides-theming--docs)** — light/dark, OKLCH, the `data-theme` switch.
- **[Guides/Design Tokens](?path=/docs/guides-design-tokens--docs)** — the three-tier system, live swatches.
- **[Guides/Accessibility](?path=/docs/guides-accessibility--docs)** — WCAG AA, contract a11y props.
- **[Contributing](?path=/docs/contributing--docs)** — story authoring conventions + status taxonomy.

## Architecture

- **Vue 3.5+** with Composition API and `<script setup lang="ts">`
- **TypeScript** strict mode, full type coverage
- **Tailwind CSS 4** with CSS-first design tokens
- **tailwind-variants (tv)** for type-safe variant styling (ADR-04)
- **Reka UI** for headless interaction primitives (ADR-07)
- **OKLCH color system** for perceptually-uniform colors

## Design Tokens

All components consume a **three-tier** token system — **primitive → semantic →
component** — exposed as `var(--dz-*)` CSS variables. See
**[Design Tokens](?path=/docs/guides-design-tokens--docs)**. Use the **Theme**
toolbar toggle above to switch between light and dark.

## Contract Spec

Every component follows Contract Spec v1 with canonical prop groups:

- **Appearance**: `size` (xs/sm/md/lg/xl), `variant`, `tone`
- **Behavior**: `disabled`, `loading`, `readonly`
- **State**: `invalid`, `error`, `required`
- **Accessibility**: `id`, `ariaLabel`, `ariaLabelledby`

Components carry a **status badge** (experimental / beta / stable / deprecated) in
the sidebar and docs header — see [Contributing](?path=/docs/contributing--docs#component-status).
