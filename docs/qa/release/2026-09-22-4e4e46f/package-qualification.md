## How to read a blocked row

A `blocked` row is **not** a failure of this lane and does not fail the exit
code. It records that the row could not run for a named reason — almost always
that no second-tier tarball is installed, which is not this repository's work to
obtain. A blocked row with no reason would be a defect; there are none.
